# 阅窗：朋友试用安装与注意事项

适用版本：0.13.0。更新日期：2026-10-31。

阅窗提供侧栏对话、划词翻译与解释、链接预览与摘要、词句收藏、跨页研究。当前以开发版方式小范围试用，安装和更新需要手动操作。

## 先准备哪些文件

请向提供者索取正式打包的文件：

- `reading-assistant-0.13.0.zip`：扩展，所有人都需要。
- `yuechuang-helper-0.13.0.zip`：本地助手，仅使用 ChatGPT 官方订阅连接时需要。

包内没有提供者的 API Key、ChatGPT 登录凭证或浏览器数据。每位使用者填写自己的接口与 Key，或登录自己的 ChatGPT 账号。本项目没有代充值、共享额度或统一账号服务。

当前主要验证环境为 Windows x64 + Chrome 120 及以上版本。助手仅提供 Windows x64 成品，macOS、Linux、Edge 和其他 Chromium 浏览器的助手安装暂未适配。运行成品无需安装 Node.js、Go 或 Python。

## 安装扩展

1. 将扩展 ZIP 解压到固定目录，例如 `D:\Apps\Yuechuang\extension`。请保留这个目录。
2. 打开 Chrome 的 `chrome://extensions`，开启右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择直接包含 `manifest.json` 的目录。
4. 点击阅窗工具栏图标，打开侧栏，再进入「设置」。若图标被收起，可从 Chrome 的扩展菜单打开或固定。

这是加载可信开发代码的试用方式，扩展尚未通过 Chrome 应用商店发布和审核。Chrome 官方将未打包加载定位为开发用途；正式长期分发可以改走应用商店渠道。[Chrome 分发说明](https://developer.chrome.com/docs/extensions/how-to/distribute)

## 选择自己的连接方式

| 项目 | 模型 API | ChatGPT 订阅（官方登录） |
| --- | --- | --- |
| 凭证 | 自己的服务商 API Key | 自己的 ChatGPT 账号及套餐用量授权 |
| 额外安装 | 无 | Windows 本地助手 |
| 当前覆盖 | 侧栏对话、划词、摘要、跨页研究 | 侧栏对话 |
| 消耗 | 所填接口对应的 API 用量或余额 | 账号实际获准使用的套餐额度 |

使用 ChatGPT 订阅进行侧栏聊天后，划词、摘要和跨页研究仍需另外配置 API。设置里只有上述两种连接，已移除旧「GPT 网页」模式。

### 使用模型 API

1. 在「侧栏对话连接」选择「模型 API」，点击「保存连接」。
2. 在下方接口设置填写自己的 Base URL、模型标识和 API Key，按提示授权接口域名并保存。
3. 点击「保存并测试连接」会实际调用一次模型；普通保存连接不调用模型。

请使用自己信任的接口服务商。勾选保存 Key 后，Key 会保存在本机浏览器扩展存储中，当前没有额外的应用层加密；不勾选时仅保留在本次浏览器会话中。接口服务商的域名、模型名和费用以该服务商为准。

### 使用 ChatGPT 订阅

1. 在设置中选择「ChatGPT 订阅（官方登录）」，复制当前显示的「阅窗扩展 ID」。每位朋友都要复制自己安装后的 ID。
2. 解压助手包，在解压目录打开 PowerShell，执行以下命令，将 `实际扩展ID` 换成刚复制的内容：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\helper-install.ps1 -ExtensionId 实际扩展ID
```

3. 安装后重新加载扩展、重开侧栏，点击检查助手，再进入官方登录流程，亲自完成账号登录和套餐用量授权。
4. 选择实际返回的模型并保存，切回对话发送简短问题，确认能收到完整回答。

助手安装在当前 Windows 用户目录中，无需管理员权限。Chrome 按需启动助手，助手处理授权和加密凭证，不安装 Windows 服务或开机启动项。完成授权后可以关闭登录页，无需保留 ChatGPT 标签页。

助手只允许安装命令指定的扩展 ID。更换加载目录或浏览器配置后若 ID 变化，需要按新 ID 重新运行安装脚本。当前助手尚未数字签名，系统或安全软件可能提示；遇到拦截先向提供者核对文件，不需要关闭系统防护。

每个人的套餐资格、模型列表、额度和网络环境可能不同。「已登录」与「允许使用套餐用量」需要分别满足，最终以完整回答返回为准。官方授权会为用户自己的账号注册连接，无法通过复制别人的安装目录继承额度。[OpenAI Docs：官方登录与注册](https://developers.openai.com/siwc/token-sharing-open-source/sign-in)

## 数据与使用范围

- 本项目没有云端存储服务。发送的问题、必要历史和主动读取的网页文字，会传给你选定的模型服务商；服务商自身的数据处理规则仍适用。
- 聊天记录保存在本次浏览器会话中，关闭侧栏后可再打开查看，重启浏览器后会清除。它不会自动出现在 ChatGPT 官网历史中，也不会读取官网记忆或历史聊天。
- 词句收藏和手动保存的研究报告留在本机，浏览器重启后仍在。重要资料可先导出；卸载扩展或清除扩展数据会造成丢失。
- 网页读取需要相应网站权限。普通对话不自动读取当前网页；划词发送选区及邻近语境，摘要和研究发送当前可读取的网页内容。
- 划词重试、补充例句、摘要和研究会产生模型调用。跨页研究每个目标页一次分析，最后再汇总；长文分段摘要可能调用多次，界面会提示计划。
- AI 回答与摘要可能有误，技术结论和引用请结合原文核对。Chrome 内置页面、部分 PDF、图片文字和限制嵌入的网站可能无法读取或预览。

## 更新、卸载与反馈

当前没有自动更新。收到新版后，先停止任务、关闭侧栏，将新版完整解压到原来的扩展目录，再到扩展管理页点击「重新加载」，并刷新需要阅读的网页。尽量保持路径不变，避免重新添加造成 ID 变化；更新前可导出收藏和研究报告。助手仅在提供者说明需要更新时重新安装。

卸载扩展后，助手仍需单独卸载。在助手包目录运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\helper-uninstall.ps1
```

该命令默认保留本地授权凭证。需要清理凭证时，可先在阅窗中退出账号，再在卸载命令末尾加 `-RemoveCredentials`。不使用官方订阅的朋友无需安装或卸载助手。

反馈问题请提供：版本号、Chrome/Windows 版本、所选连接方式、操作步骤、错误文字；官方订阅问题可复制设置里的连接诊断。截图先遮住 Key、邮箱和私人内容。不要发送 Token、授权回调链接、`credentials.bin` 或整个 Chrome 用户目录。
