# M2 划词交互修订验收记录

日期：2026-10-26。版本：0.3.1。此轮根据 M2 0.3.0 试用反馈修订，不重新开启第一阶段验收。当前范围与可复现标准见 [M2 方案](M2语境解释与翻译方案.md)。旧版本报告、截图和安装包保持原位置。

状态：开发与本地模拟验证完成，已生成可安装包；待用户试用本轮交互和真实模型结果。

## 用户体验修订

- 完成真实文字选择后，附近自动显示深色紧凑操作条，提供翻译、解释和关闭。自动展示不调用模型；只有用户点击动作才开始一次请求。
- 点击后直接在同一选区附近显示流式结果，无需右键或二次确认。原生右键路径仍可使用，Google 搜索和复制保留。
- 英语词语或短句翻译的补充入口为“双语例句”，请求 1—2 组英文例句及对应中文译文；解释的补充入口为“用法示例”，请求具体情境，适用时给最小代码。核心答案和示例分区展示。长段落隐藏不适用的例句入口。
- 保持真实选区及所在段落，避开表单、密码框、编辑区、隐藏内容和扩展自身回答；M1 链接拖动不会触发划词工具条。
- 更换选区、点击空白、滚动、关闭、导航或权限变化会清理旧状态并取消相关请求；旧请求不能覆盖新答案。

## 验证范围

确定性单元与后台检查覆盖示例类型、双语提示要求、完整翻译、核心与示例分区、真实文档身份、捕获标识、取消、无 Key 与权限，以及请求隔离。

浏览器测试以真实鼠标或键盘选择、真实工具条按钮和生产后台为主要路径，验证主页面及真实页内预览 iframe、工具条零请求、点击恰好一次、选择保持、窄屏、滚动和关闭、A/B 连续查阅、无有效选区、编辑区排除与 M1 冒烟回归。仅原生右键补充路径使用临时测试副本的菜单监听者辅助触发，并在报告中单独声明。

## 本轮修复与验证边界

- 跨文档切换时显式关闭旧卡片、释放旧 Port，避免残留卡片的重试按钮失去响应；同文档重试仍保留当前捕获。
- 整段选择的上下文以实际选中的最后一个文本节点确定，避免原生三击附带的下一段空边界扩大采集范围。
- 浏览器夹具定位屏外文字后等待两帧再开始真实选择，先消化定位产生的滚动事件；页面实际滚动仍按设计关闭临时工具条。
- 原生右键补充路径在单独的新临时 profile 中使用仪器化菜单监听者，随后核对临时副本已恢复生产文件；不把菜单监听者触发等同于点击 Chrome 原生菜单项。新版主工具条路径无需这层辅助。

模拟结果验证实现和数据流，真实模型的例句自然度与翻译质量须用本机配置的服务评估。未读取已有浏览器凭据或真实 Key。短英语入口依据选区长度和拉丁字母特征判断，其他拉丁文字的短选区也可能出现该入口。

## 用户试用步骤

1. 在 Chrome 扩展管理页重新加载当前 `dist`，再刷新需要阅读的页面；也可解压新 ZIP 后加载。
2. 选中一个英语词语或短句，确认附近直接出现“翻译／解释”，尚未点击时不生成回答。
3. 点击翻译，查看原位译文；需要时点击“双语例句”，检查英文示例句和中文译文成对显示。
4. 选择技术概念点击解释，再按需查看“用法示例”；在链接预览内重复两种操作。
5. 检查关闭、滚动、连续换词和原有右键搜索是否符合自己的阅读习惯。
