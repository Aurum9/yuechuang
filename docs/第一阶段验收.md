# M1：链接预览与摘要的独立交付及验收

版本：v0.1 草案  
日期：2026-10-25  
状态：历史初版验收基线。第一阶段已由用户于 2026-10-26 确认验收通过；最终交付取舍、自动化证据与用户确认见 [本轮验收记录](页内预览与全文摘要验收.md)。下文保留最初标准。

## 1. 阶段目标

用户可以本地加载扩展，填写自己的接口配置，拖动文章链接打开真实网页小窗，在同一小窗中手动或自动取得中文摘要，随后关闭并继续原来的阅读。

M1 交付后可以独立使用。配置页、网络调用或拖动演示中的任何单独一项，都不构成本阶段完成。

## 2. 交付物

1. 可在 Chrome“加载已解压的扩展程序”中直接安装的构建目录和 ZIP。
2. 完整源代码、锁文件、构建命令及简短安装说明。
3. 模型设置页：Base URL、模型标识、Key、Key 记住选项、连接测试、自动总结开关。
4. 链接拖动触发、独立原网页预览小窗、摘要浮层及取消／重试／打开普通标签页入口。
5. 可复现的测试夹具、自动化检查命令和人工验收记录；记录中明确 Chrome 版本、接口协议、模型标识和测试页面，排除 Key。

初版预览明确采用独立 Chrome 小窗；保持原网页样式。Sider 式页内浮层、正文阅读模式和划词解释不在 M1 通过条件中。

## 3. 验收环境与准备

- Chrome 120+；实际交付时记录测试版本。
- 一个用户可用的 Chat Completions 兼容接口和支持流式文本输出的模型。Key 由用户在本机填写。
- 通过扩展设置启用相关 HTTPS host 权限；测试夹具可单独授予 loopback HTTP 权限。
- 一份公开技术文章、一份外语文章；另准备确定性的本地页面和模拟 API。
- 本地页面至少包括：链接索引、带独特标识的文章 A／B、带 `X-Frame-Options: DENY` 和 `frame-ancestors 'none'` 的文章、延迟出现正文页、超过 24,000 字符的长文、登录表单页、跨域重定向页。
- 模拟 API 能返回分段流式结果、401、429、超时和延迟结果，包含“立即返回响应头、静默 45 秒、再发文本”的流式夹具；记录请求计数及请求体，用于检查是否误调用。计数以每个用例开始时为基线，连接测试的请求单独记录。

模拟服务只用于开发验收，不作为日常使用所需组件。日常运行无需额外安装服务端。

## 4. 标准操作流程

1. 加载扩展并打开设置，填写接口地址、模型和 Key；运行连接测试。
2. 保持自动总结关闭，打开链接索引或搜索结果页，并记下当前滚动位置。
3. 拖动文章链接，移入扩展“预览”投放区并松开。
4. 小窗加载目标原网页；手动点击“总结”，查看流式中文摘要。
5. 开启自动总结，再拖动另一篇文章；检查无需再次点击即可生成摘要。
6. 快速切换文章、取消生成、关闭预览；返回原来源页继续阅读。

## 5. 必须通过的用例

| 编号 | 操作与条件 | 可观察的通过标准 |
| --- | --- | --- |
| M1-01 安装配置 | 重新加载构建目录，填写接口配置并测试 | 配置页可用；真实 API 能返回文本；无 Key 时仍可使用原网页预览 |
| M1-02 触发与原习惯 | 普通点击、选择文字、拖动链接到预览投放区、拖向标签栏 | 普通操作保持可用；投放后只打开一个目标预览；用户原有右键 Google 搜索入口可继续使用 |
| M1-03 原页位置 | 从来源页中部拖动文章并关闭小窗 | 来源页 URL 不变；在无页面自身布局变化的夹具上，滚动位置误差不超过 2 CSS 像素 |
| M1-04 真实网页 | 打开文章和拒绝 iframe 嵌入的夹具 | 小窗显示真实文章样式与可操作链接；不把提取的文字冒充完整网页；拒绝 iframe 的页面仍可顶层加载 |
| M1-05 手动总结 | 自动总结关闭，预览文章后点击总结 | 点击前 API 生成请求增量为 0；点击后得到当前目标页的摘要；显示来源标题／最终 URL，支持复制 |
| M1-06 自动总结 | 开启自动总结后预览一篇无缓存的新文章 | 正文就绪后只产生 1 个有效生成任务；关闭开关后，新预览不自动调用；明确点击总结仍可调用 |
| M1-07 摘要针对性 | 对 A／B 使用不同正文标识；再测真实文章和超长夹具 | 请求体包含目标文章的正确标识；真实摘要包含文章主题和主要事实，不能只复述导航／页面标题。超长正文按上限截取并显示截取提示；真实质量检查允许模型措辞不同 |
| M1-08 流式与取消 | 使用分段和静默 45 秒流式夹具；生成中点击停止或关闭小窗；后台 DevTools 保持关闭 | 完成前可看到部分回答；静默夹具能继续收到输出；停止后不再追加，连接中止，任务状态查询停止；预览网页仍可阅读。取消不保证服务商退还已产生费用 |
| M1-09 快速切换 | A 延迟返回时立即预览 B | 小窗复用；A 请求被取消或结果被丢弃；B 面板始终只显示 B 的输出 |
| M1-10 导航与动态正文 | 预览内跳转；或等待延迟正文后重新读取 | 旧摘要被清空；新摘要绑定最终页面；普通导航不自动遍历生成；重新读取可取得新加载的正文 |
| M1-11 失败与恢复 | 错误 Key、429、接口格式不兼容、无正文、登录夹具、超时、后台中断 | 给出明确状态和重试入口；原网页保持可浏览；不自动重复发起付费请求；无正文／登录内容不冒充文章进行自动摘要 |
| M1-12 去重 | 对同一页面连续点击；完成后在同一会话再次预览；再切换到相同模型名的另一个接口 | 进行中的请求被合并；相同内容和配置可命中会话缓存；显式刷新重新生成；切换接口／Key 后不能沿用旧服务缓存 |
| M1-13 本机 Key | 分别测试会话 Key 和主动记住 Key；重启浏览器 | 默认会话 Key 重启后消失；记住选项按设置持久化；Key 不出现在页面 DOM、内容脚本消息、URL、日志或普通设置导出中 |
| M1-14 网络与存储 | 使用无外部资源的夹具查看网络与扩展存储 | 除目标页面加载外，扩展模型请求仅到已配置接口；无自建服务请求、无统计上报、无 storage.sync；正文无永久记录。真实网站自己的资源请求单独识别 |
| M1-15 权限与受限内容 | 测试拒绝／撤销权限、来源已授权但目标未授权、跨域跳转后的最终域未授权，以及受限协议／页面 | 未授权目标与最终页面不读取正文、不发模型请求；设置页或扩展入口明确显示缺少权限，原网页可保留正常浏览；受限页面显示不支持；恢复权限后可重试 |
| M1-16 摘要开关持久化 | 保存开关，重启浏览器 | 自动总结设置按本机配置恢复；无有效 Key 时不发送生成请求，并提供配置入口 |

## 6. 体验与性能目标

- 在本地夹具、已完成授权、暖启动条件下，投放链接至预览窗口创建目标为 1 秒内；页面实际加载时间单独统计。
- API 返回第一段文本后，界面在 300 毫秒内展示；不将模型的首段延迟承诺为扩展性能。
- 摘要浮层可折叠且不锁定整页滚动；窄窗口下仍有明确关闭入口。
- 原网页载入和模型生成状态分开显示，摘要失败不遮挡网页。
- 切换链接后即刻重置目标标识；关闭预览后终止当前客户端请求，不留下持续运行的摘要任务。

## 7. 验证方式与完成判定

建议自动化检查集中在有实际风险的逻辑：SSE 任意分块解析、重复请求合并、A／B 异步隔离、取消和超时、错误码、本机／会话 Key、消息发送方及目标绑定。浏览器端使用支持扩展的 Chromium 持久上下文和本地夹具验证；最后在实际 Chrome 完成人工流程。

M1 完成需同时满足：

- M1-01 至 M1-16 全部通过，验收记录附必要截图、请求计数和失败恢复结果。
- 至少一份真实技术文章和一份真实外语文章完成“预览—摘要—关闭返回”。
- 使用真实配置接口完成一次生成；仅通过模拟 API 不算实机完成。Key 缺失时可交付待实机验证版本，状态保持“待验收”。
- 拿到构建产物即可使用，不依赖后续阶段、临时开发服务或开发者在后台手工操作。
- 网站差异、模型兼容性和已知不支持范围在交付说明中明确列出；不得把所有失败页面统称为范围外来规避夹具标准。
