# M5：侧边栏与直接对话

日期：2026-10-28。版本：0.6.0。

用户希望点击扩展图标就进入阅读工具，默认打开对话，并通过标签使用设置和跨页研究。本阶段将入口统一到 Chrome 原生侧边栏，同时保留现有页内阅读流程。

## 范围与入口

侧栏顶部提供四个标签：**对话、跨页研究、收藏、设置**。新创建的侧栏文档默认显示对话。点击图标由 Chrome 的 `sidePanel` 行为打开侧栏，新增 `sidePanel` 权限，现有网站访问权限仍由用户按需授权。

对话直接位于侧栏顶层；研究、收藏和设置使用扩展自己打包的页面，在首次选择时加载。后续切换标签只隐藏和显示同一页面，保留表单草稿、展开状态及进行中的研究。研究运行时可以切到对话提问，聊天与研究独立执行。

旧设置、收藏和研究页面仍可单独打开。侧栏中的内部导航链接切换对应标签。现有链接拖动预览、划词工具条、解释、翻译、例句和词句收藏继续使用。

此版提供一个当前聊天会话，不加入聊天历史列表、长期聊天存档、聊天导出、附件、自动读取当前网页、自主搜索或网页操作。

## 使用方法

1. 在 `chrome://extensions` 重新加载扩展，确认版本为 **0.6.0**；首次安装可解压 `release/reading-assistant-0.6.0.zip`，加载包含 `manifest.json` 的目录。
2. 点击扩展图标打开侧栏。未配置模型时，对话页会显示“前往设置”；也可直接点击“设置”标签。
3. 填写 Base URL、模型和 Key，授权模型接口所在域名后保存。直接对话只需要接口权限；网页查阅和研究还需授权相应文档网站。
4. 切回“对话”，输入问题并点击“发送”。Enter 发送，Shift + Enter 换行；中文输入法确认候选时不会误发送。回答会逐步显示，可继续追问或复制。
5. 需要比较资料时选择“跨页研究”，填写问题和 1—5 个最终链接并授权，点击开始。任务运行时可以切回对话或查看收藏，再切回研究查看进度。
6. 点击“停止生成”保留已收到的片段；点击“新对话”并确认，会停止当前生成并清空整个会话。取消确认则保留当前消息和任务。

点击标签、编辑草稿、保存模型配置、搜索收藏或查看已存报告不会调用模型。“保存并测试连接”会调用一次模型；发送一条聊天最多调用一次；研究继续遵循每页一次分析、最后一次汇总、总计最多 6 次的规则。

## 对话规则与中断

每次请求使用系统说明、此前完整完成的用户和助手轮次，以及本次问题。后台保留真实的 `user`／`assistant` 消息角色。对话不会自动读取网页、收藏、研究结果或其他标签里的草稿。

停止或失败的回答保留片段并明确标注未完成，该轮的用户问题与助手片段都不会作为完整历史送入下一次请求。此前成功完成的轮次继续参与后续对话。输入超限、预算不足、配置缺失或接口未授权时，不发送模型请求，界面保留待发送问题便于调整。

限制如下：

| 项目 | 规则 |
|---|---|
| 单条问题 | 最多 6,000 个字符 |
| 会话长度 | 最多 40 条消息，用户和助手各算一条；失败或停止的轮次也占用 |
| 同时生成 | 当前聊天会话最多一个活动请求 |
| 单次预算 | 沿用设置中的 2,048—128,000 tokens；估算完整输入、每条消息开销、1,536 tokens 输出预留及余量 |
| 超限 | 提示清空会话或调整预算，不静默裁剪历史 |
| 重试 | 无自动重发、切换模型或付费重试 |
| 清空与停止 | 命令绑定当前请求编号，旧命令不会取消较新的请求 |

关闭发起对话的侧栏文档或其连接断开会停止生成，关闭其他只查看同一会话的侧栏不会停止所属请求。保存配置、清除 Key、撤销权限或开始连接测试，也会取消聊天。切换标签、启动聊天和启动研究互不取消彼此的聊天与研究任务。

后台恢复时，未完成的会话标记为中断，不自动恢复付费请求。仍可查看收到的片段、继续使用此前完整轮次，或确认清空会话。停止会终止客户端连接，服务商是否继续计费由所用接口决定。

## 数据与权限

| 数据 | 存储与生命周期 |
|---|---|
| 当前对话消息与检查点 | `chrome.storage.session.chatSession`，只保留当前浏览器会话，重启后清除 |
| 输入框及研究、设置草稿 | 当前页面内存；切标签保留，不提供关闭后的草稿持久化保证 |
| 设置 | `chrome.storage.local` |
| API Key | 默认 session；仅用户勾选记住时保存到 local |
| 词句收藏、手动保存的研究报告 | 既有 local 存储，浏览器重启后保留 |

同一扩展会话中的侧栏共用一个当前聊天会话。聊天不会写入 local，收藏与研究报告也不会因“新对话”而删除。会话存储写入失败时，停止或拒绝本次生成并显示提示，恢复存储后由用户明确发送。

所有存储继续限制为 `TRUSTED_CONTEXTS`。聊天后台仅接受扩展顶层 `sidepanel.html` 的专用 Port；设置、研究和收藏页面只保留各自的消息权限，网页内容脚本不能管理这些数据。嵌入视图只允许精确的扩展内部页面及固定嵌入参数，没有向网页公开扩展页面资源。

Key 仅供后台直连接口使用，不进入聊天状态或聊天检查点。发送内容包含当前配置的 Key 时会拒绝；模型输出完整回显该 Key 时会隐藏。界面中的模型输出采用纯文本，HTML 不执行。

插件没有新增应用后端、账号、同步或统计服务。远程模型会收到用户发送的内容和本次所需的完整对话，其服务端处理与保留规则由用户选择的接口决定。

## 独立验收

本阶段可以单独验收，不重新要求第一阶段整体验收。自动化结果与构建校验见 [M5 验收记录](M5侧边栏与对话验收记录.md)。

建议先使用本机模拟接口完成流程，再使用自己的 Key 验证实际回答质量。

| 编号 | 操作 | 预期结果 |
|---|---|---|
| M5-01 | 在自己的 Chrome 点击扩展图标 | 打开原生停靠侧栏，首次进入对话；无需先打开设置页 |
| M5-02 | 依次选择四个标签，调整侧栏宽度 | 页内切换正常，输入和按钮可见，内容无横向溢出 |
| M5-03 | 在设置填写接口、模型、Key 并保存，切回对话 | 配置生效；保存和切换本身无模型调用 |
| M5-04 | 连续提问两次，第二次要求承接前文 | 回答流式显示，能引用完整上轮；模拟请求含正确助手角色 |
| M5-05 | 输入 HTML 片段，复制模型回答 | 片段按文字显示，脚本不执行；复制得到当前回答 |
| M5-06 | 输入未提交的聊天、研究或设置草稿，来回切标签 | 草稿保留，同一嵌入页面不重载 |
| M5-07 | 在生成中停止，再次提问 | 保留片段并标注未完成；新请求排除停止的这一轮 |
| M5-08 | 点击新对话，分别取消和确认 | 取消保留会话；确认后消息清空，活动请求停止 |
| M5-09 | 降低预算，发送超过完整预算的消息 | 显示预算提示，不产生新模型调用，不自动截历史 |
| M5-10 | 运行两页研究，切到对话发送消息，再切回 | 研究页面和任务保留，聊天与研究均能完成；报告可保存及导出 |
| M5-11 | 生成中清 Key、保存配置或撤销接口权限 | 当前生成停止，无后续自动模型调用 |
| M5-12 | 生成中关闭所属侧栏文档，再重新打开 | 请求停止，保留片段；未完成请求不自动重发 |
| M5-13 | 浏览器彻底退出后，用同一配置重新打开 | session Key 和聊天清除，手动保存的报告与收藏仍在 |
| M5-14 | 从普通网页或错误的扩展页面尝试聊天、设置及研究接口 | 拒绝跨角色或网页来源，Key 不进入聊天、报告或导出 |
| M5-15 | 无 Key 时打开收藏和已存研究报告 | 可以查看、搜索、导出及按原有确认流程删除 |

无头浏览器测试可以验证生产侧栏文档、四个标签、嵌入页面、多轮角色、停止、预算、持久化边界和窄屏布局，并检查原生侧栏的清单与行为配置。**它未实际点击用户 Chrome 的扩展图标，也未验证原生停靠侧栏表面。** M5-01、实际停靠宽度和原生关闭体验需要用户本机检查；真实模型的兼容性与回答质量同样保留为人工验收。
