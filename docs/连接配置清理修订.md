# 连接配置清理修订

日期：2026-10-30。版本：0.13.0。

## 问题与原因

用户切换到「模型 API」并保存连接时，界面仍可能提示 ChatGPT 网页操作失败。旧设置代码给 API 连接也附带了网页连接的模型值，随后使用网页模式的模型格式规则校验。已选官方订阅模型如 `gpt-6.1-terra` 含有句点，无法通过这条无关的校验；通用异常提示又把错误归为网页连接失败。

本次将连接配置与网页运行模块分开。API 连接选择仅保存 `{provider:'apiKey',model:''}`；真正的接口地址、模型标识和 Key 继续使用原 API 设置。官方订阅连接使用自己的模型规则。普通连接保存与读取不检查助手、不触发登录、不申请额外权限，也不发送模型请求。

## 两种连接与升级

- 设置仅保留「ChatGPT 订阅（官方登录）」和「模型 API」。删除网页模式的设置、侧栏状态和运行入口，生产包不再包含三份网页桥接脚本。
- 已保存的 API 设置、Key、收藏和研究报告保留。已有 API 或官方订阅选择继续使用；更换连接不会把模型值混用。
- 旧网页连接升级为未选择模型的官方订阅配置，并显示提示，等待用户选择所需连接。不会自动切换到保存的 API Key 发起计费请求。
- 拒绝旧页面残留的网页连接消息；重新加载扩展并重开侧栏后使用新版入口。
- 官方登录、自动搜索、回答详情与流式解析沿用现有实现。助手 EXE 未修改，无需重新安装或授权。
- 修正 320/390 像素窄屏下官方操作按钮挤成竖排的问题，改为可换行的两列按钮。

旧网页源码、历史测试与旧发布包作为开发记录保留；它们未进入当前生产包。

## 用户复测

1. 在 Chrome 扩展管理页重新加载阅窗，再关闭并重新打开侧栏。
2. 设置中确认只有官方订阅和模型 API 两项，选择「模型 API」并点击保存连接。
3. 确认显示保存成功，重新打开设置后仍选中模型 API，原接口配置与 Key 保留。

本次验证保存行为无需点击「保存并测试连接」；该按钮会按既有规则额外发起一次模型请求。
