# M5 快捷选项修订

日期：2026-10-28。版本：0.6.1。

## 修复内容

聊天空白页的“解释一个概念”“帮我梳理思路”原先仅在输入为空时填入文字，导致先点一个选项后，另一个选项无法切换。

本次规则：

- 输入为空时显示两个选项。
- 点击选项后，如果尚未手动修改预置文字，可以来回切换。
- 手动输入、粘贴或修改文字后隐藏两个选项，保留用户草稿；即使手动输入的文字恰好与预置相同，也按用户草稿处理。
- 清空输入框后恢复显示。切换侧栏标签继续保留输入及隐藏状态。
- 发送失败恢复的草稿按受保护内容处理，避免快捷选项覆盖。

仅调整侧栏的草稿标记和选项显示；点击选项不发送消息，也不产生模型请求。模型请求、Key、收藏和研究的存储行为沿用 0.6.0。
