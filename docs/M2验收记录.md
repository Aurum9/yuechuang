# M2 右键语境解释与翻译验收记录

日期：2026-10-26。版本：0.3.0。范围与可复现标准见 [M2 方案](M2语境解释与翻译方案.md)。第一阶段已验收的 0.2.0 报告、安装包和结论继续保留。

本轮新增 `contextMenus` 权限，复用现有本机配置、可信存储和模型直连。解释、翻译都读取当前选区及就近可见段落，浮层显示于同一文档；主页面和 M1 页内预览 iframe 使用相同流程。

## 验证方法

- 单元与后台测试检查选区与段落边界、提示和预算、原生菜单 URL、精确 tab/frame/document、无 Port 不调用模型、快速连续请求、旧 Port 命令、取消、手动重试、翻译说明展开、配置写入隔离、权限和导航。
- DOM 测试在独立 Chromium 中检查隐藏/编辑区排除、超长段落的完整句、选区和阅读位置保持，以及短小 viewport 的浮层边界。
- 集成测试使用真实 Chromium、鼠标选词和可信 `contextmenu` 事件，调用本机模拟 SSE 模型。Chrome 原生菜单项选择通过临时测试扩展的监听者仪器化触发，未将其记为用户原生菜单实机验收。
- 测试辅助入口只存在于临时副本的运行内存；生产 `dist` 无测试入口。安装后恢复磁盘副本的生产文件并核对逐文件 SHA-256，另核对受测构建、源码重建和 ZIP。

最终结果：**65/65 单元、后台与 DOM/界面检查通过，28/28 浏览器集成用例通过**。其中 11 项选区与界面检查包含 8 项独立 Chromium DOM/UI 检查；集成浏览器为 Chromium 156.0.8078.4。本轮源码重建、受测 dist 和 ZIP 的 9 个文件逐字一致，发布校验已通过。

## 人工待验项目

1. 用户 Chrome 中实际选取原生右键菜单项，在普通技术文章、外语文章和预览内完成解释与翻译，确认 Google 搜索继续共存。
2. 使用本机设置的真实模型，评估解释是否符合上下文、译文是否完整保留术语、数字和限定条件。无需向聊天发送 Key。

这些项目属于 M2 的新功能验收，第一阶段已确认的结论保持有效。

## 边界

单次选区最多 6,000 字符、语境最多 10,000 字符，模型预算另外检查。优先使用完整段落；极长段落尝试在实际选中位置附近保留完整句，无法满足时明确提示。PDF、图片文字、编辑器、输入框和不可读 frame 不在本轮选区阅读范围。

关闭、导航或 Port 断开会释放当前选区快照；回答不作为永久历史存储。后台中断时需要重新选择文字后通过右键菜单查阅。停止和取消终止客户端连接，服务商计费以所选接口规则为准。
