一次直接本机诊断在读取模型列表的网络阶段失败，未发起模型 POST。使用环境代理重试被自动审批拒绝，理由是代理未核实、可能接触 OAuth 凭证；未通过其他方法绕行该代理。后续使用插件既有 Chrome 请求路径采集结构化诊断。

用户提供的 Chrome 扩展卡片截图显示版本 0.10.1 与红色「错误」按钮。后续连接诊断已将发送失败定位到响应头检查；扩展错误日志中的内容脚本异常需要单独看待，不能仅凭卡片状态将两者归为同一原因。

## 0.10.2：根据真实诊断调整响应头检查

用户最新提供的 0.10.1 诊断包含以下固定字段：助手状态 `ready`、`planAuthorized: true`，失败阶段 `headers`、HTTP 200、`contentType: missing`、失败原因 `nonEventStream`。

这说明现有账号和套餐权限已被插件识别，请求也已得到 HTTP 响应；旧检查在尚未读取响应正文时，仅因未看到 `Content-Type: text/event-stream` 而拒绝继续。现有证据不包含正文，无法判断缺头由哪一层造成，也不能据此认定正文已经是可用回答。

0.10.2 的调整仅限这一边界：

- 请求明确添加 `Accept: text/event-stream`。
- 响应存在正文且 `Content-Type` 缺失时，交给既有严格 SSE 与 Responses 事件解析器继续检查。
- 明确返回 JSON、HTML 等其他响应类型仍拒绝；缺失响应类型时的 HTML、普通 JSON、空正文、无有效完成事件、失败或中断也不能当作成功回答。
- 大小、超时、取消和完成状态校验保留；仅有效 `response.completed` 计为成功，不自动重试或回退到其他连接。

2026-10-30，用户按 0.10.2 更新复测提示反馈「可以收到了。」据此确认侧栏真实消息接收已恢复，详见 [用户实机复测](验收证据/0.10.2/用户实机复测.md)。本次反馈没有单独确认多轮追问、全部官网标签关闭、流式终态及助手退出情况，不将这些项目一并标为通过。无需为这次插件修订重新安装助手。

## 0.10.2：内容脚本重载保护

内容脚本增加对失效扩展上下文与异常 `lastError` 读取的保护，确保浮窗和端口断开后仍可执行本地清理。9 项内容脚本异常模拟检查通过。

另在独立临时 Chromium 配置中执行实际 MV3 扩展重载，4 项检查通过，确认旧内容脚本上下文已失效，随后滚动、点击、同页导航与关闭浮窗未出现未捕获异常。测试使用本机网页夹具，没有访问用户的 Chrome 配置、真实账号、助手凭证或模型接口。报告为 `test-results/content-extension-reload/0.10.2.json`，发布核验仅在报告存在且对应当前构建时纳入。

0.10.1 基线尝试没有复现用户截图中的未捕获异常，不能把它写成“修复前失败、修复后通过”的实证。上述重载检查也没有验证用户原网页上的当前状态。

本轮自动化验证：0.10.2 生产构建、356 项单元与集成检查、10 项 SIWC UI 模拟检查、16 项侧栏模拟回归、9 项内容脚本异常模拟回归、4 项实际 MV3 重载检查通过。发布核验脚本核对受测构建、dist 与 ZIP，并在实际重载报告存在时检查其构建指纹、上下文失效证据、零模型请求与无未捕获异常；缺失该可选报告时会明确标注，不能写成已验证实际重载。

## 本次交付

新增官方 Sign in with ChatGPT 连接，暂接入侧栏直接对话。用户显式选择并保存新连接后使用，现有 API Key 和旧网页连接保持独立。划词、摘要、跨页研究的模型配置仍使用现有 API Key 设置。

助手负责本应用的 OAuth、加密凭证、串行续期和退出；插件只在内存持有访问令牌，通过公共 Responses API 发出请求。正常聊天无需 ChatGPT 标签页。首次及重新授权需要用户在官方页面完成登录和同意套餐用量权限。

本机已安装助手，仅允许本机安装的阅窗扩展 ID，安装目标为 `%LOCALAPPDATA%\YuechuangHelper`，注册项为该助手专用 HKCU Native Messaging host。安装后直接 native 协议状态自检返回 `signedOut`，进程已退出。自检没有发起 OpenAI 注册、登录或模型请求，也不能代替 Chrome 扩展实际连接验证。

EXE：7,081,984 字节，SHA-256 `f21bd440c2a1eff16364a42c3d65d5df29165a6e0094ad213142cfb3f2f02395`。
