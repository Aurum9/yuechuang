# M5 Markdown 显示修订

日期：2026-10-28。版本：0.6.2。

聊天回答此前通过 `textContent` 输出，模型生成的 `**加粗**`、标题和列表符号会直接显示。本次为侧边栏的助手回答加入 Markdown 渲染，用户消息继续按输入原文展示。

支持标题、加粗、斜体、删除线、嵌套列表、有序列表、引用、行内代码、围栏代码块、表格、分隔线与 HTTP(S) 链接。流式生成时持续渲染，包括尚未闭合的代码围栏；停止或失败时收到的片段仍保留。长代码和宽表格在自身区域横向滚动，适配窄侧栏。

复制按钮和后续模型上下文使用原始 Markdown，渲染只影响显示。没有增加模型请求或云端存储。

## 实现与边界

使用独立的 [Marked 实例与渲染器](https://marked.js.org/using_pro)解析，原始 HTML 先转为字面文字，图片只显示替代文本，再由 [DOMPurify](https://github.com/cure53/DOMPurify)按文本结构白名单过滤。生成后的链接仅接受无用户名密码的绝对 HTTP(S) 地址，明确点击后在新标签打开，添加 `noopener noreferrer` 和 `no-referrer`。

不执行模型 HTML，不自动加载图片、脚本或其他远程资源。解析异常时回退完整纯文本。当前没有数学公式、Mermaid 或代码语法高亮；代码内容和缩进正常显示。依赖随扩展本机打包，许可一并进入 ZIP。
