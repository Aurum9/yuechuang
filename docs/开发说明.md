## 模块

| 文件 | 职责 |
| --- | --- |
| `src/background.ts` | 预览窗口生命周期、发送方/文档校验、任务隔离、权限变更、连接测试 |
| `src/store.ts` | TRUSTED_CONTEXTS、本机/会话 Key、缓存串行写入与清除 |
| `src/model.ts` | 后台直连接口、SSE、取消、响应头/空闲/总超时 |
| `src/core.ts` | 协议/配置校验、SSE 分块解析、配置与正文缓存指纹 |
| `src/content.ts` | 普通链接拖动、Shadow DOM 摘要浮层、导航感知、20 秒任务状态查询 |
| `src/extract.ts` | 实际目标 DOM 克隆、Readability、代码保留、动态稳定检测与截取 |
| `src/options.ts` | 扩展自有设置页，显式权限按钮与本机设置入口 |

Service Worker 使用 `previewId + tabId + revision + browser documentId` 绑定任务；请求另有随机 requestId。权限、配置、取消操作推进操作版本，异步读取配置中的旧任务同样失效。旧 Port 的命令在等待浏览器身份查询后重新校验。窗口创建、复用、关闭串行执行；导航期间拒绝旧文档重新绑定。

正文等待最短约 700ms、650ms 稳定窗口、5 秒提取截止；无正文不请求模型。正文上限 24,000 字符，输出以安全文本显示。模型响应头等待 25 秒、流数据空闲 60 秒、总任务 120 秒。运行期间内容脚本每 20 秒向后台查询状态；终态/停止/关闭/断连立即停止查询。后台强制中断后只允许手动重试。

缓存最多 20 项，仅 `storage.session` 保存摘要及哈希，不永久保存正文。指纹包括最终 URL、正文 SHA-256、接口完整地址、模型、Key 哈希、语言和提示版本。配置保存清除缓存；写入与清除有序执行，避免并发复活已清缓存。

## 检查

```powershell
npm ci --cache .npm-cache
npm test
npm run build
npx playwright install chromium
npm run test:e2e
npm run package
npm run verify:release
```

`tests/unit.test.ts` 检查 SSE 任意分块/CRLF/UTF8、端点、缓存指纹、错误码、取消/超时、存储模式与清理。`tests/background.test.ts` 使用内存 Chrome API 和 fetch 检查消息角色、文档/URL/长度、清 Key 与旧请求竞态、旧窗口命令和缓存清除。

`tests/fixtures/server.mjs` 提供无外部资源的文章与模拟接口，支持分段、45 秒静默流、认证/限流/模型/格式/重定向/无响应头错误。`/stats` 记录请求体、模型、计数、客户端中止状态和鉴权头是否存在，忽略鉴权值；`/reset` 清空记录。连接测试与文章请求分别计数。模拟摘要按正文标识生成，仅用来验证数据流和界面行为。

端到端测试在临时独立 Chromium profile 中使用 Playwright 真实鼠标拖动，截图和 JSON 记录在 `test-results`。headless 环境的原生可选 host 授权确认框无法可靠自动处理；功能用例在测试副本中预授予 loopback 权限后恢复逐字一致的生产 manifest，生产 `dist` 不改动。初始未授权、权限撤销和最终域拒绝分别验证。真实 Chrome 的首次授权/拒绝仍列为人工项目。

报告的 `testedBuild` 包含实际受测 dist 的文件 SHA-256 和整体指纹；恢复 manifest 后比较完整测试副本，结束时确认 dist 未被改动。交付校验脚本 `scripts/verify-release.mjs` 将归档的完整/同 URL 报告与当前 dist 对应，并逐字核对 ZIP。独立执行同 URL 压力用例可设置 PowerShell 环境变量 `$env:E2E_FOCUS = 'reuse'` 后运行 `npm run test:e2e`，结束后用 `Remove-Item Env:E2E_FOCUS` 恢复完整模式；归档时复制两份 JSON 到 `docs/验收证据`。

## 真实接口验收

在本机设置填写自己的接口、模型和 Key，完成一篇真实技术文章及一篇外语文章的预览、摘要、关闭返回。检查主题与关键事实、正常右键 Google 搜索、拖向标签栏、首次授权和拒绝、网站实际登录上下文。记录浏览器/模型版本、文章地址和结果，不记录 Key。无需向聊天发送凭据。

运行时无需 Node、测试服务器或构建工具；加载 `dist` 后直接由扩展与目标网站和指定模型服务通信。
