# M6：ChatGPT 网页连接（实验）

更新：2026-10-29；版本：0.7.1。用户已确认官网可聊天，插件发送失败；当前网页对话连通性尚未恢复。0.7.1 修复状态误报并增加诊断，见 [修订记录](M6连接状态与诊断修订.md)。

## 已确认需求

用户接受使用自己已登录的 ChatGPT 账号，并允许对话留在 OpenAI 历史里。插件设置、收藏及已存研究报告继续只保存在当前浏览器；不新增应用后端。API Key 连接继续保留，用户手动切换对话连接。

本阶段只接入侧栏“对话”。网页预览摘要、划词翻译／解释和跨页研究沿用原有 API Key 配置。两个配置区域独立，切换连接不会自动调用模型或改用另一种计费方式。

## 使用方式

1. 在 `chrome://extensions` 重新加载本项目的 `dist`，重新打开侧栏。
2. 进入“设置 → 侧栏对话连接”，选择“ChatGPT 网页（实验）”。
3. 点击“打开 ChatGPT 登录”，允许访问 `https://chatgpt.com/*`，在打开的官方网页亲自登录。已有登录页会被复用。
4. 保持该 ChatGPT 标签页打开，回到插件点击“检查登录 / 刷新模型”。以实际返回的账号和模型列表为准。
5. 选择模型，点击“保存对话连接”，再切回“对话”发送问题。登录和模型读取成功时仅显示对话尚未验证；只有完整收到一次回答，才显示最近一次对话成功。
6. “新对话”清空插件当前会话并解除远端关联；OpenAI 历史仍保留。“解除当前网页对话关联”也不会注销 ChatGPT。
7. 发送失败时，回到设置点击“复制连接诊断”，反馈失败阶段、HTTP 状态与固定分类。此操作不复制账号、模型、聊天正文、原始服务器响应或凭据。刷新登录只重新检查身份和模型，不验证对话能力。

没有本地助手进程。插件不代填账号、密码或验证码，不导出浏览器 Cookie；登录由用户在 ChatGPT 网页完成。浏览器账号登出在 ChatGPT 网页操作。扩展后台重启后需要重新检查登录和模型。

## 实现

设置与侧栏通过白名单 RPC 访问连接管理器。管理器只在用户明确检查或发送时操作已授权的 ChatGPT 顶层文档，校验标签页 URL 与 `documentId`，注入幂等的 isolated-world 内容脚本，并用限定名称的 Port 通信。

内容脚本从固定同源 `/api/auth/session` 获取当前网页会话，再访问固定 `/backend-api/models` 和 `/backend-api/conversation`。凭证只留在内容脚本当前请求的闭包中，不通过 Port 发送给后台，不写入扩展 local/session/sync，不进入页面 DOM、收藏或导出。后台只接收脱敏账号显示名、模型列表、回答文字和对话关联标识。

支持普通文本 SSE 快照的流式回答。只在完整成功后保留远端 conversation/parent 关联；下一轮输入与之前完成历史逐字匹配时才续接原远端对话。清空、失败、停止、权限变化、页面导航或配置变化会解除关联。丢失关联时以已完成的本机上下文开启新远端会话。

本机聊天仍按白名单保存在 `chrome.storage.session.chatSession`，重启浏览器后清除；连接方式及模型保存在 `chrome.storage.local.webChatConfig`。远端关联和已检查账号状态只存在后台内存。账号状态不写入聊天检查点。

每次发送最多一次对话 POST，无自动重试或 API Key 回退。总超时 120 秒、流空闲超时 60 秒，模型回答最多 40,000 字符；原有单条 6,000 字符、40 条消息及完整上下文预算继续生效。网页服务对最终输出长度和配额作独立限制，插件的输出预留用于本地预算估算。

## 限制与验收范围

网页接口属于非公开协议，可能因服务端版本、账号、模型、风控或地区变化而失败。403、验证要求、不兼容格式或额度错误均停止请求并显示固定提示；不自动解决验证或绕过网页保护。刷新登录成功或出现模型列表不能证明真实对话成功。

自动测试使用独立 Chromium 配置和本地模拟响应，测试访问的 ChatGPT URL 全部被拦截。测试不读取用户 Chrome 登录信息，不使用真实账号或消费真实额度。生产构建保持原始代码与权限声明；浏览器测试的临时授权仅用于引导测试配置，之后还原并重载。

独立验收步骤：用户在自己的 Chrome 完成登录、刷新出实际模型、发送一轮真实问题，再追问一轮；检查答案及 ChatGPT 历史是否符合预期。随后停止生成、开启新对话并确认旧的 OpenAI 历史仍在。真实账号连通性和网页接口兼容性以这次人工验收为准。

## 研究依据与备选

已核查本机 Sider 5.35.3 静态程序文件中的 Webapp provider、session 请求、网页对话与标签页代理，见 [代码核查](SiderWebapp代码核查.md)。该证据确认实现路径存在，无法证明任何具体账号当前可用。

OpenAI 官方 Sign in with ChatGPT OAuth 路线保留为备选，其本地运行环境和回调要求会引入额外组件。本轮实现采用浏览器会话连接；未实现 OAuth、套餐 scope 授权或本地助手。官方参考：[接入概览](https://developers.openai.com/siwc/quickstart)、[本地应用](https://developers.openai.com/siwc/token-sharing-open-source)、[用户说明](https://learn.chatgpt.com/docs/sign-in-with-chatgpt)。
