# M3 词句收藏验收记录

日期：2026-10-27。版本：0.4.0。

状态：实现、自动验证和安装包完成，等待用户试用验收。第一阶段的用户验收确认继续有效。

## 交付内容

- 翻译或解释完成后，在结果卡点击“收藏”，保存原文、回答、已生成的例句、附近语境和来源。
- 主页面和预览 iframe 均可使用；来源取自实际回答文档。
- 相同来源、词句和操作类型更新已有条目。补充例句后点击“更新收藏”即可保存到同一条目；普通更新保留已有例句。
- 结果卡“收藏夹”和设置页“词句收藏”均可进入管理页。支持全文关键词搜索、翻译／解释筛选、展开语境和例句、打开来源、单条确认删除。
- 按最近更新时间排序；数据未变化的刷新保留展开状态。删除后原结果卡可直接重新收藏。
- 支持导出全部或当前筛选结果为 JSON／Markdown，只导出收藏字段。当前不提供导入。
- 仅存储在当前浏览器配置的本机 local 区，不使用云同步。收藏与管理不调用模型；无 Key 和网站授权也可查看、搜索、导出和删除。

## 独立试用步骤

1. 在 Chrome 扩展页重新加载当前项目的 `dist`，再刷新阅读网页；或解压安装包并加载包含 manifest.json 的目录。
2. 划选一个英语词句，点击翻译。回答完成后点“收藏”，再点“收藏夹”，核对原文、译文、语境及来源。
3. 回到结果卡补充“双语例句”，点击“更新收藏”；收藏夹中应仍为同一条，展开后能看到例句。在链接预览里收藏一个技术解释，核对来源属于预览目标。
4. 搜索词句或译文，切换翻译／解释筛选，导出 JSON 或 Markdown。取消一次删除，再确认删除；原结果卡应恢复“收藏”。
5. 关闭并重开浏览器，确认剩余收藏仍在；未保存 Key 时，收藏夹仍能打开和导出。

## 边界

收藏上限为 500 条或 6 MiB，达到限制会报错并保留旧条目。损坏或不兼容的数据会明确报错，避免覆盖原数据。卸载扩展或清除扩展数据会删除本机收藏，需要时先导出；Chrome 的持久化与访问级别行为见[官方 storage 文档](https://developer.chrome.com/docs/extensions/reference/api/storage)。

模拟测试证明数据流、界面操作和持久化。真实模型的翻译与例句质量、用户 Chrome 的原生权限提示及原生右键菜单项选择仍需本机体验；右键补充测试使用临时测试副本触发已注册菜单监听者，报告已单独声明。收藏主要路径使用真实鼠标选择和生产后台，无测试调用入口。
