## 本轮关键边界

- 网页凭证只在 ChatGPT 内容脚本局部请求中使用，不发送到后台，不写入扩展存储或 UI。
- 只在用户明确检查／发送时请求固定 ChatGPT 地址；无自动模型调用、重试或 API 回退。
- 新文档与账号切换需重新检查身份；账号发生变化时，在对话 POST 前停止。刷新连接会解除旧远端关联。
- 只有当前 assistant 消息完成才保留远端 parent；旧消息完成状态和 `end_turn: false` 无法将新片段标为成功。
- 停止、断开 Port、页面导航／关闭、权限撤销和超时会中止请求。停止与失败的片段不进入后续完整历史。
- 新对话仅清空本机当前会话；没有调用 OpenAI 删除历史或退出登录的接口。
- 不处理网页验证挑战、额外保护协议、工具调用或 WebSocket 私有协议；遇到不支持的响应会明确失败。

## 尚待用户本人验证

浏览器自动测试全部采用独立配置与本地模拟响应；ChatGPT URL 被测试框架拦截，未使用真实账号或消费真实额度。原生工具栏、停靠侧栏和系统权限对话框也未由无头测试验证。
