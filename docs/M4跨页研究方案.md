# M4：本地跨页研究

日期：2026-10-27。版本：0.5.0。根据用户对浏览器任务助手的讨论，以及“继续任务吧”的请求，实现可独立验收的跨页研究首版。

## 目标与范围

面向技术文章和外语文档阅读，把用户明确提供的几篇资料围绕同一问题整理、比较，并保留可回看的来源证据。

> 输入研究问题与 1—5 个链接 → 明确授权这些网站 → 逐页阅读并提取证据 → 汇总带引用的报告 → 手动保存或导出。

首版固定采用只读、顺序执行的流程。后台按输入顺序临时打开标签，读取目标文档，关闭任务创建的阅读标签，再分析该页。每篇最多一次模型调用，最后一次汇总，整个任务最多 6 次。模型只生成约定的数据结构，不能自行增加链接或执行网页操作。

本轮不加入自主搜索、沿链接扩展阅读、点击网页控件、填写表单、发送消息或提交交易。登录页、付费墙、验证码和需要复杂交互才能看到的内容由用户自行处理；研究页会呈现读取失败或内容范围提示。

## 使用与交互

- 研究页从设置页进入，可返回设置或词句收藏。
- 研究问题最多 1,500 个字符；文档每行一个，最多 5 个，拒绝重复链接与无效地址。
- 网页支持 HTTPS，以及本机 `localhost` / `127.0.0.1` HTTP。Chrome 应用商店等受限页面不读取。
- “授权所填网站”由用户明确点击，只请求所填文档网站的访问权限；模型接口沿用设置页授权。输入和授权本身不调用模型。
- 开始后显示当前阶段、实际模型调用次数、各来源状态、读取范围与失败原因。研究任务页需要保持打开，可随时停止。
- 当前任务状态在后台更新。查看历史报告时，轮询不会切换正在阅读的历史内容；可通过“查看当前任务”返回。
- 报告分为资料概览、比较结果、结论。每条陈述附来源编号与证据编号，点击后定位到对应的要点和原文引句。
- 部分来源失败时可以基于剩余有效证据生成报告，并明确提示缺失范围。只有一个有效来源时提示属于单页资料整理。全部失败时不生成完整报告。

## 执行与内容约束

扩展后台管理任务状态、网站权限、临时标签、正文提取、模型调用和停止流程。研究页通过受信任消息接口查看或管理任务，通过文档绑定的 Port 维持任务页生命周期；关闭任务页会停止所属任务。

任务对每个来源执行：检查授权、创建临时标签、等待目标顶层文档、向准确的 documentId 注入正文读取器、提取正文、再次核对文档和授权、关闭任务标签、提取结构化证据。首版严格接受用户所填的最终 URL；同域路径跳转或跨域跳转均提示改用最终链接，跨域还需明确授权。

如果用户将任务创建的临时标签导航到其他页面，清理过程会核对当前地址，避免关闭已经被用户另作他用的标签。任务停止、超时、权限撤销或模型配置变化后，不继续发送新的研究模型请求。

单页分析把研究问题、网页标题、地址和正文发给配置的模型接口，要求返回最多 4 条发现。每条包括中文要点和连续原文引句。程序对引句做空白规范化后，检查其确实存在于取得的正文中，未通过的发现会丢弃并提示。

最终汇总仅使用通过上述检查的来源要点和引句。程序检查报告结构，以及每条引用所指的来源和发现编号是否存在，拒绝不存在或未完成的证据引用。

**原文引句核对只证明这段引文存在于取得的正文中。它不能保证模型对引文的解释、比较关系和结论语义绝对正确。** 用户仍可点击引用、打开来源，检查上下文与推理是否恰当。

网页和模型内容都通过纯文本显示。网页资料中的指令不会获得插件操作能力；模型没有工具调用入口，也不能读取其他收藏、报告或 Key。

## 调用预算与中断

每次调用前估算完整消息、输出预留及额外开销，使用设置页现有预算。超过预算时提示失败，该页正文不会悄悄截短后继续研究。正文提取的可见范围或局部读取限制单独显示。

一页一次分析、一次最终汇总，无自动模型重试；请求开始时计入调用次数。模型返回无效 JSON、无可核对引句或无效引用时，显示对应失败。重新开始由用户明确触发，避免失败后循环产生费用。

单任务有 12 分钟时限；文档加载有独立超时。停止会中止正在进行的模型请求，并保留已经获得的来源证据。浏览器或后台中断后，检查点显示中断状态，不自动恢复付费请求。浏览器进程退出后，纯本地插件中的任务无法继续执行。

## 本机数据与隐私

- 复用用户设置的 Base URL、模型与 Key，插件直连模型接口；不新增应用后端、云端记录或同步服务。远程模型接收完成研究所必需的网页资料，其服务端保留规则由用户所选接口决定。
- 研究页只接收 `hasKey` 等配置状态，不读取 Key，不直接访问存储；正文读取脚本也不会获得 Key。
- 当前任务检查点保存在扩展会话存储，包含状态、来源发现与报告，不保存模型 Key 或完整网页正文。已保存报告位于 `chrome.storage.local.researchReports`。
- 保存由用户手动触发，只允许当前完整完成的报告。同一个任务再次保存更新同一条记录；后台串行写入，避免并发覆盖。
- 报告保存问题、输入链接、来源标题与地址、证据、最终报告、调用次数、时间及范围提示，不包含模型配置、Key 或其他收藏。
- 最多 20 份已存报告，JSON UTF-8 总量最多 1.5 MiB。达到上限提示用户先导出或删除，不自动淘汰旧报告。
- 历史报告可离线查看、逐份导出 Markdown 或确认后删除。首版不提供导入、一键清空或自动复习。
- 存储保持 `TRUSTED_CONTEXTS`；网页内容脚本无法通过研究消息列出或删除报告。遇到本机数据损坏时拒绝覆盖原数据。
- 浏览器重启后本机已存报告仍保留；卸载扩展会删除扩展本机数据，可提前导出需要保留的报告。

## 独立验收标准

| 项目 | 通过标准 |
| --- | --- |
| 输入与明确触发 | 无效、重复、超过 5 个链接或超长问题被拒绝；输入、授权和打开研究页均不产生模型调用。 |
| 网站权限 | 授权按钮只请求所填文档网站；缺少文档或模型接口权限时无法开始读取或调用。 |
| 顺序阅读 | 按输入顺序读取准确顶层文档，任一时刻最多有一个本任务阅读标签，读完自动清理。 |
| 页面变化 | 读取前后导航、跨域跳转与权限变化被发现；用户改作他用的临时标签得到保留。 |
| 模型调用上限 | 最多 5 次单页分析与 1 次汇总，实际请求有计数，失败不自动重试。 |
| 原文证据 | 展示真实取得的来源与引句；伪造、拼接或不存在的引句被丢弃，空证据来源不纳入报告。 |
| 报告引用 | 报告每条陈述带有效引用；点击可定位相应来源证据；错误来源编号与发现索引被拒绝。 |
| 部分失败 | 各来源状态和失败原因可见；部分失败报告说明范围，单来源报告有提示，全部失败不生成完整报告。 |
| 停止与中断 | 手动停止、关闭所属研究页、撤销权限和超时均停止后续请求；中断后不会自动恢复模型调用。 |
| 预算 | 超预算或正文资源超限给出明确错误，不静默裁切后提交模型。 |
| 保存与历史 | 完成后明确保存；刷新和重启后能查看；正在查看历史报告时，当前任务进度不会将其替换。 |
| 导出与删除 | Markdown 包含问题、报告、来源和证据，不含 Key／配置；删除先确认，取消保持原记录。 |
| 数据边界 | 网页脚本不能列举、保存或删除研究报告，模型请求不附带其他收藏与报告。 |
| 布局与回归 | 桌面及 390px 研究页和设置入口可用，长链接与报告文本不越界；现有划词、预览与收藏功能正常。 |

自动模拟验证、真实模型效果和用户体验验收分别记录。已有 M1—M3 验收结论继续保留，本轮产出 0.5.0 的独立构建与检查证据。
