# 0.14.0：纯扩展 ChatGPT 订阅授权

更新：2026-11-05。当前方案不需要本地助手、PowerShell、Go 或 Node.js 运行时。Windows 和 macOS 使用同一个 Chrome 扩展 ZIP。其它浏览器、Windows 实机和真实套餐的最终兼容性仍需分别验收。

## 与旧调查的差别

重新静态检查本机 Sider 5.35.3 和 5.35.6 的发行代码，确认除 Webapp 外，它还包含 ChatGPT plan usage 的 OAuth 路径：`dynamic_agent_client`、`chatgpt.tokens.use.direct`、`http://127.0.0.1:1455/auth/callback`、标签页 URL 观察、令牌交换和浏览器存储续期。5.35.6 的该模块位于 `background.js` 第 117 行，字符偏移约 768447 起。检查只读取发行程序，没有读取用户 Cookie、运行存储或真实凭据。

因此，旧《Sider Webapp 代码核查》不能解释套餐 OAuth，也不能据此认定所有订阅连接都必须安装 helper。当前实现独立编写，不复用 Sider 或其它应用的身份和凭证。

## 当前实现

- 扩展创建自己的登录标签页，生成独立的 state、nonce、S256 PKCE 和稳定 host ID。应用名称为「阅窗」。
- 首次以 `dynamic_agent_client` 注册，取得本账号签发的 client ID；后续复用该注册。仅接受本轮 tab ID、固定 loopback origin/path 和原始 state；拒绝重复关键参数、错误 client ID、子框架和其它标签页回调。
- 同时观察 `tabs.onUpdated` 和顶层 `webNavigation.onBeforeNavigate`，直接接收 URL 中的授权结果。不启动 HTTP 监听器，不要求本机端口存在服务。完成、取消、关页或超时后清理本轮事务与标签页。
- 固定访问 OpenAI 授权、令牌、OIDC 元数据、JWKS 和 API 域。用 WebCrypto 验证 RS256 签名、issuer、audience/azp、expiry、nonce 和账号绑定；身份登录与套餐权限分别判断。
- 令牌临近过期时串行续期并保存最新 refresh token；临时网络失败保留凭证，终止性失效要求重新授权。模型生成不自动重试，也不自动切到 API Key 计费。
- 普通登录由 Chrome API 活动维持后台执行；PKCE 事务存入 session storage，事件监听器在模块初始化时同步注册，后台真正终止后仍可接回原回调。五分钟事务期限用 alarms 和运行中计时器共同清理。
- 退出时先清除本机 access、refresh 和 ID token，再使用本次退出操作内存中的 refresh token 尝试撤销远端会话。无法确认撤销时会显示提示。保留账号注册和 host ID，方便再次登录。

## 凭证存储与官方指引的边界

长期凭证存在 `chrome.storage.local.siwcCredentialsV1`，登录事务存在 `chrome.storage.session.siwcPendingAuthV1`。两个存储区设置为 `TRUSTED_CONTEXTS`，网页内容脚本不可读。凭证不写入页面 DOM、配置导出、聊天记录、诊断、同步存储或发布 ZIP。

这不是 Windows DPAPI 或 macOS Keychain，没有额外应用层加密。能读取浏览器资料的本机程序或用户仍可能获得凭证。共用设备应在使用后退出；泄露时还需在 ChatGPT 设置中撤销应用授权。

当前 [OpenAI 授权指引](https://developers.openai.com/siwc/token-sharing-open-source/sign-in)描述实际启动 loopback listener；[账号与会话指引](https://developers.openai.com/siwc/token-sharing-open-source/profiles-and-sessions)要求令牌不进入浏览器存储。本方案的回调接收和凭证保存与这两点不同，是为免本地组件而选择的纯扩展试验。不能把隔离浏览器模拟通过表述为 OpenAI 已正式支持这种宿主形态，也不能承诺长期兼容。

## 升级与分享

从助手版升级需重新在扩展内登录。不会读取旧助手、Codex、Sider 或其它程序的凭证。旧 helper 不再被当前扩展调用，其源码与脚本保留为历史参考；如需清理旧安装，参见旧版卸载说明。

分享 `release/reading-assistant-0.14.0.zip` 和《安装与使用说明》即可。每个人在自己的浏览器完成授权，不分享浏览器资料或本机扩展存储。尚未上架商店，仍需解压并通过开发者模式加载；正式公开分发需另走商店发布。

## 验证

```sh
npm ci
npx playwright install chromium
npm test
npm run build
npm run test:siwc-ui
npm run test:siwc-auth
npm run test:sidebar
npm run package
npm run verify:release
```

`test:siwc-auth` 使用真实隔离 Chromium 和生产代码，模拟 OpenAI 网络响应，验证授权标签页回调、真实 WebCrypto 签名校验、内容脚本存储隔离、两轮对话、CDP 真正终止后台后的事务恢复、续期和退出。测试副本只在安装阶段预授域权限，随后恢复生产文件。未使用真实账号、真实模型或用户 Chrome；原生权限弹窗和浏览器停靠侧栏不属于该项验证范围。

真实账号待验收：在自己的 Chrome 加载 `dist`，完成一次官方登录、模型发现、完整回答和追问，再关闭重开浏览器检查续期与退出。Windows 与 macOS 的真实账号结果应单独记录。
