# M5 侧边栏与对话验收记录

日期：2026-10-28。版本：0.6.0。

状态：实现、本机模拟验证及安装包已完成，等待用户体验验收。范围与详细使用方法见 [M5 方案](M5侧边栏与对话方案.md)。已有阶段的验收结论和安装包保留。

## 本次交付

点击扩展图标通过 Chrome `sidePanel` 打开原生侧边栏，新创建的侧栏默认显示“对话”。顶部四个标签为“对话、跨页研究、收藏、设置”。设置和研究无需从独立设置页进入；侧栏中首次加载的页面在切换后保持挂载，保留未提交的草稿与研究任务。

新增直接多轮流式聊天，使用既有模型接口和 Key，支持停止、复制及确认后开始新对话。请求包含此前完整完成的用户和助手轮次；停止或失败的轮次保留片段，但不进入后续完整历史。聊天与研究可分别运行，发送聊天不会中断研究。

聊天仅保存到当前浏览器会话的 session 存储，重启后清除；收藏和明确保存的报告继续保存在 local。对话不会自动读取网页、收藏或研究报告。每条输入最多 6,000 字符，一个会话最多 40 条消息；超出完整上下文预算时提示，不静默裁剪或自动重发。

## 独立试用步骤

1. 在 `chrome://extensions` 重新加载当前 `dist`，确认版本为 0.6.0；使用 ZIP 时先解压，再加载包含 `manifest.json` 的目录。关闭旧扩展页面和旧侧栏，刷新阅读网页。
2. 点击扩展图标，确认打开 Chrome 停靠侧栏并进入“对话”。点击四个标签，调整侧栏宽度，确认输入和操作可见。
3. 在“设置”填写接口、模型和 Key，授权模型接口域并保存。回到“对话”连续提问两次，第二次承接上文；观察流式生成并尝试复制。
4. 在生成中点“停止生成”，确认收到的片段仍在，且可继续提问。点击“新对话”，先取消确认，确认原消息保留；再次点击并确认，检查会话清空。
5. 在设置或研究中留下未提交草稿，切换标签后回来，检查草稿保留。运行两页研究，切到对话发送问题，再回到研究查看进度和结果，保存报告并导出。
6. 关闭侧栏后重新打开，检查未完成生成已停止。彻底退出浏览器后重开，确认聊天与默认 session Key 清除，收藏及明确保存的研究报告仍在。

## 验证边界

浏览器自动化直接打开生产侧栏文档并操作其中的真实控件，检查了原生侧栏 API 的清单和行为配置。它没有实际点击用户 Chrome 的扩展图标，也没有验证原生停靠侧栏表面；工具栏点击、原生关闭及实际停靠宽度需在本机 Chrome 试用。

本轮没有请求真实模型，接口兼容性与回答质量仍需用户配置模型后检查。插件不增加云端存储；发送给远程模型的文字由所选接口处理，其服务端保留规则由服务商决定。

原生授权对话框、真实网站兼容性和右键菜单项选择继续属于人工体验范围。划词原生菜单补充验证使用临时测试副本调用已注册监听者；主要划词工具条、侧栏、研究和收藏流程使用生产后台，报告注明各自范围。
