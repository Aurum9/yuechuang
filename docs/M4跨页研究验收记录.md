# M4 跨页研究验收记录

日期：2026-10-27。版本：0.5.0。

状态：首版实现、本地模拟验证和安装包完成，等待用户试用。范围见 [M4 方案](M4跨页研究方案.md)，已有阶段记录保留。

## 本次交付

设置页新增“跨页研究”。用户提供具体问题与 1—5 个文档最终链接，明确授权后，扩展顺序读取文档、提取可核对的原文证据，生成来源比较表及带引用的概览、比较结果和结论。引用可定位到原文引句。

首版采用限定链接的固定只读流程，每页最多一次分析，最后一次汇总，总计最多 6 次，不自动重试。部分失败明确列出原因和报告范围，全部失败不生成完整报告。超预算保留失败原因，不静默截断正文；无效引句和不存在的报告引用被拒绝。

支持手动停止、关闭任务页停止、配置或权限变化时停止；当前任务保留会话检查点，后台恢复时标记中断并停止自动调用。完成报告可手动保存到本机，重复保存同一任务更新原记录，支持 Markdown 比较表和引句导出、历史查看及单条确认删除。最多 20 份或 1.5 MiB，不自动逐出。

## 独立试用步骤

1. 在 Chrome 扩展管理页重新加载当前 `dist`，或解压新 ZIP 后加载包含 manifest.json 的目录；刷新已打开的扩展页面和阅读网页。
2. 在设置页确认模型、Key 和接口域已配置，点击右上角“跨页研究”。输入一个具体比较问题和 2 个相关技术文档的最终链接，每行一个。
3. 点击“授权所填网站”，完成原生权限提示后点“开始研究”。观察逐页状态与调用次数；两页均成功时应为 3 次。
4. 查看来源比较表，点击引用核对下方引句与原文。保存报告并导出 Markdown，检查问题、比较表、报告、来源和证据齐全。
5. 开始另一个任务后停止，确认后续页面不再分析；关闭任务页也应停止。重启浏览器后，在“已存报告”中查看上一份明确保存的报告。
6. 可加入一个无法读取的链接，确认失败页面单独列出，报告明确说明有效来源范围。不要把部分结果当作所有链接都已分析。

## 验证边界

本轮没有用真实模型进行质量测试。原文存在性与引用编号验证只能确认引句真实出现、引用目标有效，模型的解释、比较和推理仍需结合上下文判断。

首版仅接受所填最终 URL。同域路径重定向及跨域重定向会提示用户改用最终地址；不会自动扩大链接范围或处理网页表单。已改作其他用途的任务标签保留供用户查看。后台或浏览器中断后不自动继续付费请求。

原生权限对话框、用户 Chrome 原生右键菜单项选择和真实网站兼容性保留人工体验范围。划词的原生菜单补充测试使用临时副本调用已注册菜单监听者，报告明确声明；研究流程和主划词工具条使用生产后台及真实页面操作。
