# 阅窗本地助手最小方案

> 历史说明：适用于 0.10—0.13 版本。0.14 起改为纯扩展授权，无需安装助手；参见[当前安装说明](安装与使用说明.md)。

日期：2026-10-29。状态：首版已实现并构建；模拟测试及安装后的本机状态自检通过。真实账号授权和关闭官网后的模型调用仍待验收。

## 目标与用户体验

仅支持用户本人的 Windows 电脑和 Chrome 中的阅窗插件。采用官方 Sign in with ChatGPT 授权和 ChatGPT plan usage；保留现有 API Key 入口。

一次安装完成后，所有日常操作仍在阅窗侧栏进行。首次或需要重新授权时打开 OpenAI 登录授权页。正常聊天不需要任何 ChatGPT 标签页，包括后台标签页。

助手由 Chrome 按需启动；登录、读取凭证或续期操作结束后退出。无需开机启动、Windows 服务、托盘界面或常驻 HTTP 服务器。仅登录期间临时绑定 `127.0.0.1` 的可用端口，完成、取消或超时后关闭。

## 最小交付物

- 一个 Go 编译的 Windows 可执行文件 `yuechuang-helper.exe`，运行端无需另装 Node.js 或 Python。
- 当前用户的安装、卸载脚本；安装时生成 Native Messaging host 配置，写入阅窗自己的 HKCU 注册项，限定真实阅窗扩展 ID。无需管理员权限。
- 一份助手专用的本地加密凭证文件和非敏感注册信息。

已构建 EXE 7,081,984 字节，约 6.75 MiB；助手压缩包约 2.81 MiB。内存占用尚未实测。交付一个原生程序，不引入独立浏览器运行时。

## 责任划分

| 部件 | 责任 |
| --- | --- |
| 侧栏与插件 service worker | 账号状态、模型选择、对话和翻译、Responses API 流式请求、本地记录 |
| 本地助手 | OAuth 授权、令牌校验、Windows 加密保存、按需续期、撤销会话和退出 |
| OpenAI 官方服务 | 登录与同意授权、签发令牌、套餐用量与模型服务 |

插件与助手通过 Chrome Native Messaging 的标准输入输出通信。常规操作不开放本机网络端口。页面内容脚本不能直接调用助手；插件后台仅接受经过校验的固定操作。

助手保管 access、refresh、retained ID token；以当前 Windows 用户范围的 DPAPI 加密落盘。插件只暂时在后台内存持有调用 API 所需的 access token；不得写入 chrome.storage、IndexedDB、聊天记录、诊断或日志。续期令牌和 ID token不返回插件。

## 最小通信接口

- `status`：返回助手版本、账号标签、是否已授权套餐用量、是否需要重新登录；不返回令牌。
- `login` / `cancelLogin`：启动或取消一次官方授权，成功后只返回账号与授权状态。
- `getAccessToken`：按需读取或续期，返回短期访问凭证和到期信息；操作完成退出。
- `logout`：按官方发现文档的撤销端点结束可续期会话，清除本地令牌并报告撤销是否确认。

同一会话的续期需要跨进程串行化，避免同时启动的助手竞争轮换 refresh token。插件端合并并发的凭证请求。登录未完成、用户拒绝套餐授权、续期失效、额度耗尽应分别显示原因。

## 首次登录与后续请求

1. 用户在阅窗点击官方品牌规范要求的 Continue with ChatGPT 按钮。
2. Chrome 启动助手，助手先启动回调监听器，再生成独立的 state、nonce 和 PKCE 事务。
3. 以阅窗自己的名称和稳定 host ID 走 dynamic registration，接收并保存本应用签发的 client ID，校验身份及套餐权限。
4. 助手加密保存凭证，停止回调监听并退出。插件显示账号和权限状态。
5. 发送问题时，插件按需调用助手取得访问令牌，随后直接调用官方模型列表和 Responses API。
6. 正常请求使用 `store: false`、`stream: true`；收到 `response.completed` 才标记成功。需要上下文时由本地记录构造，不假设同步至 ChatGPT 官网历史。
7. 令牌接近到期后才按需启动助手续期；授权被撤销或不能续期时，提示用户重新登录。

助手只访问本应用的凭证文件。注册使用本应用实际身份，不读取或复用 Codex、官方 Chrome 插件、Sider 的登录凭证或客户端身份。

## 第一个可独立验收的阶段

先验证官方授权与插件的最小闭环，不改动阅读、收藏、跨页研究功能。

验收要求：

1. 完成一次当前用户安装，侧栏可以识别助手版本；未安装时提示清楚。
2. 登录后分别显示身份已验证、套餐用量已授权的状态；拒绝授权不能显示为可聊天。
3. 将所有 ChatGPT 标签页关闭，插件通过官方 API 列出本账号可用模型，并完成一条简短消息，收到 `response.completed`。
4. 请求完成后助手退出，关闭侧栏后也无残留助手进程和端口；再次使用由 Chrome 自动启动。
5. 使用受控测试验证刷新轮换和并发保护，真实刷新仅在正常到期或需要时发生。
6. 退出后清除插件临时凭证和助手本地令牌；区分已确认远程撤销与仅本地退出。
7. 安装可撤销；卸载只移除阅窗自己的 host 配置与注册项，凭证清理选项明确。

真实账号是否能取得套餐授权、扩展直接调用官方 API 的行为，仍需实际验证；不能以模拟测试替代真实连通验收。

## 官方依据

- [OpenAI：注册与登录](https://developers.openai.com/siwc/token-sharing-open-source/sign-in)：动态客户端、loopback 回调、PKCE、身份及用量权限校验。
- [OpenAI：账号与会话](https://developers.openai.com/siwc/token-sharing-open-source/profiles-and-sessions)：续期、撤销、轮换并发和凭证保存要求。
- [OpenAI：模型与推理](https://developers.openai.com/siwc/token-sharing-open-source/models-and-inference)：公共 Responses API、模型列表、流式完成标准。
- [Chrome：Native Messaging](https://developer.chrome.com/docs/extensions/develop/concepts/native-messaging)：Chrome 启动本地进程、通信、允许的扩展 ID 和当前用户注册。
- [Microsoft：CryptProtectData](https://learn.microsoft.com/en-us/windows/win32/api/dpapi/nf-dpapi-cryptprotectdata)：当前用户范围的 Windows 凭证加密。
