# 自动联网搜索修订

日期：2026-10-30。版本：0.11.0。

用户明确要求由模型自行判断联网时机，取消此前提出的手动开关方案。本版在官方 ChatGPT 订阅请求中默认提供 `web_search`，使用 `tool_choice: auto`；普通问题允许直接回答，时效性问题、需要核实的事实或明确查资料的请求可由模型调用搜索。

## 行为

- 真实搜索事件驱动“正在联网搜索”“正在读取网页”等状态；正文中提到搜索不会制造已联网标记。
- 从最终 Responses 快照读取来源引用，保留文字位置、标题与 HTTP(S) 链接，正文内和来源区均可点击。链接使用独立页面打开并隔离 opener 和 referrer。
- 引用作为结构化数据保存于本次浏览器会话，重连后仍可显示；复制回答保持原始文本，不把界面生成的引用编号混入原文。
- 中断、停止或后台重启时，搜索标为未完成；保留已收片段和可核对的来源，不自动重发问题或更换计费路径。
- 已知功能/资格/策略限制使用固定错误提示；未知 400 不被解释为网络故障。错误正文仅在内存中有限读取以识别固定代码，不展示服务端原始错误、凭证或原文。
- 最终快照是正文与引用的依据；显式空输出不能把早期草稿计为成功。仅有效 `response.completed` 建立已完成对话。

本地助手无需修改，不依赖 ChatGPT 标签页。当前通用 API Key 路线仍使用 Chat Completions，不对任意服务商注入 OpenAI Responses 字段。

## 验证

生产构建与 373 项单元/集成检查、20 项官方登录与侧栏 UI 模拟检查、16 项侧栏浏览器回归、9 项内容异常模拟、4 项实际 MV3 重载检查、5 项实际后台停止后恢复检查通过。UI 已在 390px、320px 宽度检查，包含 Markdown、中文及 emoji、危险 URL、恶意标题、引用复制和中断恢复。浏览器检查采用隔离配置、本机夹具与虚构凭证，不调用真实账号或模型。

真实搜索能力尚未验证。原有 0.10.2 的用户真实文字回答确认，不能代替本版搜索资格与调用验证；0.10.3 的现场侧栏恢复复测也仍单独保留。

## 用户复测

重新加载阅窗并重开侧栏，使用已保存的官方订阅连接，直接询问：“请搜索 OpenAI 官方文档，说明 Responses API 如何让模型自动决定是否联网，并给出来源。”检查搜索过程与可点击的来源，再用普通问题确认可以直接回答。无需切开关或重新安装助手。

官方文档明确搜索受模型、账号和工作区政策影响。若本账号拒绝该工具，保留固定失败提示与结构化连接诊断，不声明搜索已开通，也不在后台改写请求自动重试。

依据：[Responses Web search](https://developers.openai.com/api/docs/guides/tools-web-search)、[订阅接入限制](https://developers.openai.com/siwc/token-sharing-open-source/preview-limitations)。
