# M3：本地词句收藏

日期：2026-10-27。版本：0.4.0。根据用户“来个词句收藏吧”的请求实现。

## 使用流程

> 划词翻译／解释 → 回答完成后点击收藏 → 在收藏夹查看与搜索 → 需要时打开来源或导出。

普通网页和现有预览 iframe 使用同一流程。收藏本身不产生模型调用，不改变现有链接预览和划词操作。

## 保存内容

- 原选中文字及附近语境。
- 当前完整译文或核心解释。
- 已生成的双语例句或技术用法示例。
- 来源网页标题、地址、回答类型和保存／更新时间。

同一来源 URL、同一规范化词句和同一回答类型合并为一条；再次保存更新当前回答。只有完整完成的结果允许保存；尚在生成、停止或失败的结果不冒充完整收藏。

## 管理与数据

- 收藏夹提供关键词搜索、翻译／解释筛选、语境与示例展开、打开来源、单条删除确认。
- JSON 和 Markdown 导出默认覆盖全部收藏，也可明确选择当前筛选结果。当前版本不提供导入或自动复习。
- 数据保存在 `chrome.storage.local.savedPhrases`，浏览器重启后保留；不使用同步、云端服务或模型接口。
- 保存经当前回答的文档绑定 Port 发起，记录由后台已有选区与回答构造，不接受网页自报的收藏内容。
- 列表和删除仅由扩展收藏页请求；网页内容脚本无法枚举其他收藏，local 维持 `TRUSTED_CONTEXTS`。
- 所有写入在后台串行执行，避免并发收藏／删除相互覆盖。最多 500 条、收藏 JSON UTF-8 总量最多 6 MiB，达到限制会提示，不自动删除旧收藏。
- 导出只包含收藏字段，不导出模型配置或 Key。删除默认先确认；不加入一键清空等批量操作。
- 卸载扩展会删除本地数据；需要保留时可先导出 JSON。

## 独立验收

| 项目 | 通过标准 |
| --- | --- |
| 主页面收藏 | 真实划词翻译后保存，能查看原文、语境、译文与正确来源；保存新增模型请求为零。 |
| 预览内收藏 | 技术解释在目标 iframe 中收藏，来源和语境属于该目标文档。 |
| 示例更新与去重 | 双语例句完成后更新同一收藏，数量不增加，例句和核心译文分区保存。 |
| 未完成结果 | 生成中、停止和失败时收藏不可用；旧 Port 不能保存新文档结果。 |
| 搜索与筛选 | 可按原文、回答、语境与来源检索，翻译和解释筛选正确。 |
| 持久化 | 关闭并重开独立浏览器 profile 后收藏仍在，默认 session Key 消失。 |
| 离线管理 | 无模型 Key 和网站授权也可查看、搜索、导出与删除收藏，无新增模型调用。 |
| 删除 | 删除前有确认；取消不变，确认后只删除所选条目，刷新后结果保持。 |
| 导出 | JSON／Markdown 包含预期收藏字段，不包含模型配置、Key 或其他扩展存储。 |
| 数据隔离 | 内容脚本不能读取收藏存储或通过消息列出／删除收藏；模型调用也不自动附带其他收藏。 |
| 稳定性 | 并发保存、去重更新、删除、存储损坏和配额错误有确定性测试。 |
| 布局 | 桌面与 390px 收藏页可用；结果卡片中的收藏、收藏夹和关闭入口不越界。 |

本地模拟验证和用户真实模型质量分别记录。M1 的已有验收结论保持不变；本轮只执行改动相关回归并生成 0.4.0 独立证据。
